SYS SOLUTIONS · ADMIN

Set up your private admin access

SYS Solutions admin sign-in is configured by the server owner. Add these server-side environment variables in your hosting dashboard, then visit /admin to sign in:

  • ADMIN_PASSWORD — a unique password with at least 12 characters.
  • ADMIN_SESSION_SECRET — a separate, randomly generated secret used to sign eight-hour sessions.

Keep both values private. Do not add a NEXT_PUBLIC_ prefix or share them in browser code.
